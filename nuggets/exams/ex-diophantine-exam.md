For each equation, decide whether it has integer solutions, and why. If it does, give **all** solutions with $0 \le x \le 30$. Use the Pulverizer and show all steps.

(a) $5x + 11y = 14$  (b) $14x + 35y = 20$  (c) $15x + 10y = 14$  (d) $8x + 14y = 12$

## Hint

Follow the recipe in [[diophantine-equations]]: first $\gcd$, then divide, then the Pulverizer, then the general solution $x + kb$, $y - ka$. Check each solution by substituting it.
