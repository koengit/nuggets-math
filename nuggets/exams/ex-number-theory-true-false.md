True or false? Give a proof or a counterexample.

(a) All integers greater than 1 that are divisible by neither 2 nor 3 are prime.
(b) There are operators that are associative but not commutative.
(c) There are operators that are commutative but not associative.
(d) If $p$ is prime and $a \cdot b \equiv 0 \pmod p$, then $a \equiv 0 \pmod p$ or $b \equiv 0 \pmod p$.
(e) For all integers $a > b$: $\gcd(a, b) = \gcd(a - b, a + b)$.

## Hint

For "for all" statements that are false, one counterexample is enough ([[proving-quantified-statements]]); try small numbers. (b) and (c): see [[ex-operators]]. (d): translate $\equiv 0 \pmod p$ into divisibility. (e): try $a, b$ both odd.
